# Berkas unduhan KarirMate Android

- `Laporan-Audit-KarirMate.pdf`: laporan lengkap Android dan backend, A4, 15 halaman.
- `KarirMate-Android.patch`: patch dua commit implementasi dari main sampai `fb9810326c509a62ae8983c6f2d61d1be467c193`.
- `KarirMate-Android.bundle`: Git bundle source yang sama; basis `b0c7209a51d56a523d82047d73cb0b78c9710355` harus tersedia.
- `KarirMate-Android-Unduhan.zip`: PDF, patch, bundle dan checksum dalam satu unduhan.
- `SHA256.json`: ukuran serta hash berkas di atas, kecuali ZIP.

Patch/bundle merupakan snapshot source sebelum commit lampiran ini. Commit unduhan tidak dimasukkan ke snapshot untuk menghindari arsip rekursif. Backend memiliki patch/bundle sendiri pada draft PR repository backend. Tidak ada APK, token, kredensial, database atau CV pribadi dalam lampiran.

Pada HP, buka file lewat akun GitHub yang memiliki akses repository privat, lalu gunakan tombol Download/unduh file mentah. Berkas ini merupakan unduhan nyata, bukan path filesystem cloud.
